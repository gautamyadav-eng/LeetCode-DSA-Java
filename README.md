# LeetCode DSA Java

This repository contains my solutions to LeetCode problems
implemented in Java while preparing Data Structures and Algorithms.

## Topics Covered

- Arrays
- Strings
- HashMap & HashSet
- Two Pointer
- Sliding Window
- Binary Search
- Stack
- Queue
- Linked List
- Trees

## Language

- Java

## Goal

To improve problem-solving skills, DSA concepts,
and time & space complexity analysis through consistent practice.
